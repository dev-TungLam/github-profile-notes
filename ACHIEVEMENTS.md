# GitHub achievement reference

A personal reference for checking profile achievements without confusing search totals with GitHub's internal counters.

## Inspect unlocked badges

Open https://github.com/dev-TungLam?tab=achievements and click a badge to inspect its tier and milestone history.

## Estimate Pull Shark progress

While signed in, search GitHub for:

```text
is:pr is:merged author:dev-TungLam
```

The result count includes accessible matching pull requests. It is an estimate of achievement progress: visibility, eligibility, indexing, and award delays can affect the badge independently.

## Community-documented milestones

| Achievement | Default | Bronze | Silver | Gold |
| --- | ---: | ---: | ---: | ---: |
| Pull Shark: authored pull requests merged | 2 | 16 | 128 | 1024 |
| Pair Extraordinaire: coauthored merged pull requests | 1 | 10 | 24 | 48 |
| Galaxy Brain: accepted Discussion answers | 2 | 8 | 16 | 32 |
| Starstruck: stars on a repository you created | 16 | 128 | 512 | 4096 |

Thresholds are community documented, not a contractual GitHub API. Check live badge history for the authoritative awarded tier.

## Single-step achievements

- Quickdraw: close an issue or pull request within five minutes of opening it.
- YOLO: merge your own pull request without a submitted code review. The exact eligibility checks are not fully documented; a merge alone does not guarantee an immediate badge.
- Public Sponsor: publicly sponsor an eligible developer through GitHub Sponsors. Sponsoring can cost money.

Use useful changes in repositories you control for practice. Credit actual coauthors, answer real questions, and earn stars from real users. GitHub Community Discussions no longer award achievements.
